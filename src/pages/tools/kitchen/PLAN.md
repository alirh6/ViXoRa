# 🍳 تصمیم امشب: «آشپزخونه هوشمند ویکسورا» — Kitchen OS

## چرا این ابزار؟ (تحلیل ترافیک)
- **روزانه‌ترین سؤال هر خونه ایرانی:** «ناهار/شام چی بپزم؟» → ذاتاً ترافیک روزانه + کلیک بالا
- **صفر هم‌پوشانی** با ابزارهای فعلی (مدیریت، مالی، ساختمان، رزومه، صندوق...)
- **خلأ واقعی وب فارسی:** سایت‌های آشپزی فقط بلاگن؛ «سیستم‌عامل آشپزخونه» (برنامه هفتگی ← لیست خرید خودکار ← انبار ← تایمر ← حالت پخت) به فارسی عملاً وجود ندارد
- **حلقه عادت:** استریک پخت روزانه + امتیاز + بج + پیشنهاد روزانه = برگشت هر روز
- **وایرال:** گردونه «چی بپزم؟» + اشتراک‌گذاری برنامه هفته/لیست خرید

## هدف: ۱۱۵+ قابلیت واقعی (نه بادکنک)
شمارش دقیق در FEATURES.md — هر فیلتر، هر تایمر، هر آمار، هر تنظیم = یک قابلیت.
قانون: هیچ دکمه‌ای نباید الکی باشد؛ همه‌چیز باید واقعاً کار کند.

  kt-plan.js      برنامه هفتگی + لیست خرید خودکار + انبار و انقضا

## استانداردهای کیفی
- هر مودال: ✕ + Escape + کلیک بیرون (تست خودکار)
- همه اعداد فارسی، تاریخ شمسی واقعی
- تایمرها timestamp-based (با بسته بودن تب هم دقیق)
- TTS فارسی + آلارم WebAudio واقعی
- احترام به reduced-motion + سوییچ انیمیشن
